Interfaces are state machines. Write them that way.

FOAR is a UI language with a Rust compiler. You declare each component's states, what each state shows, and which events it handles. The compiler rejects transitions that don't exist and cases you forgot, and the runtime updates the page in place.

Flags let you build states nobody designed.

        
Three booleans make eight combinations. A note that is editing and saving at once is one of them, and every handler has to guard against it. In FOAR the combinations don't exist: each state owns what it shows and the events it accepts.

      

      

        
        
      

    

  


  

    

      

        
A match that has to handle every case.

        
A switch falls through when you forget break, and says nothing when you add a case it doesn't handle. A FOAR match runs exactly one arm and must cover every variant of an enum, both true and false, or end with _. Arms that can never run are errors too.

        
Patterns can be literals, alternatives like a | b, ranges like 1..=9, and bindings with if guards. A match works as a value, as a statement, or as Match(…) in a render block, where the page only changes when the matching arm does.

      

      

        
        
$ foar check checkout.foar
checkout.foar:3:11: This match doesn't handle Payment.Invoice
(add an arm for it or `_ => …`)

        
      

    

  


  

    

      

        
What comes with the language

        
States, branching, styling, routing and server rendering are part of FOAR itself, checked by the same compiler.

      

      

        

          
Components with explicit states

          
Effects belong to states and a transition is one statement. Async work is a state that waits for its call and leaves through on_exit, or on_error when the call fails.

        

        

          
Static types, all the way to the host

          
Stores, data records, view props, assignments and transitions are type-checked, and so are calls into JavaScript declared with extern fn. Enums can carry data, and data can be generic.

        

        

          
Updates without a virtual DOM

          
Each element compiles to real DOM nodes plus the expressions that feed them. An update writes only values that changed, keyed lists keep their rows, and inputs keep focus.

        

        

          
Server rendering and hydration

          
renderToString and renderToStream run on Node or edge workers without a DOM. hydrate adopts the server's HTML in place and creates no elements.

        

        

          
Accessible by default

          
A missing alt, an unlabeled field, an icon button with no name or a misspelled ARIA attribute is a compile error. A modal Dialog, announce(), a focus ring and reduced motion are built in, and every DOM event React has is there, checked by name.

        

        

          
Routing, slots, portals and error boundaries

          
Router, Route and Link; named Slots; Portal for overlays; Catch and Fallback around anything that can fail.

        

        

          
Styling and translations in the language

          
Scoped CSS with themes and dark mode, styles that apply only in a given state, and t(key, params) with plurals plus a checker for missing keys.

        

        

          
One Rust compiler, everywhere

          
The same code builds the CLI, the formatter, a language server for editors (with a VS Code extension), and the WebAssembly compiler the playground runs in your browser.

        

        

          
Packages

          
foar.toml declares dependencies and foar.lock pins them by SHA-256, verified on install.

        

      

    

  


  

    

      

        
Measured, not promised

        
Every number here comes from this repository: pnpm bench, node scripts/measure.mjs, the test suite, and the 26-file Notes example.

      

      

        

          
FigureWhat it measures

          
            
23 KBThe runtime, gzipped: one ES module with no dependencies, including the router, server rendering, hydration and i18n.

            
278 KBThe whole compiler and type checker as WebAssembly, gzipped. It's what the playground downloads.

            
1.4 MBThe foar command: compiler, type checker, runtime and dev server in one binary, with nothing else to install.

            
13 msCompiling and type-checking the Notes app (26 files, about 2,100 lines) in WebAssembly.

            
0DOM elements created while hydrating server HTML, or while typing into a filter that keeps the same 500 rows.

            
2.5 msPer keystroke or checkbox toggle in a 500-row list, measured in happy-dom.

          
        

      

      
happy-dom is a JavaScript DOM without layout or paint, much slower than a browser, so read its timings relative to each other. Elements created is the stable measure of work.

A Notes app in 26 files

        
Folders, tags, pinned and locked notes, a rich-text editor with checklists and tables, drag and drop, context menus, keyboard navigation, three languages and dark mode.

        
Every popup, sheet and inline editor is a state. A folder row moves between Idle, Menu, Renaming and ConfirmDelete; the formatting bar between Idle, Styles, Colors, Table and Linking.

Install it in one line

        
One binary: the compiler, the runtime and a dev server. Or skip installing and use the playground.

      

      
    
        
  1. 
          
    
            
            
          
    
          
    

    curl -fsSL https://josmanvis.github.io/FOAR/install.sh | sh
    
            
          
    
          
    

    irm https://josmanvis.github.io/FOAR/install.ps1 | iex
    
            
          
    
          
    Checks the download's SHA-256 and puts foar on your PATH. x64 and arm64. All releases
    
        
    2. 
        
  2. 
          
    Start a project and open it. It reloads when you save:
    
          
    

    foar init my-app && cd my-app
foar dev
    
            
          
    
        
    3. 
        
  3. 
          
    Build it for any static host. The guide walks through the rest.
    
          
    

    foar build
    
            
          
    
        
    4.
